# Shorekeeper DeepSeek Pet

[Download for Windows](https://github.com/Doya16/shorekeeper-deepseek-pet/releases/latest) · [Demo video](https://github.com/Doya16/shorekeeper-deepseek-pet/releases/download/v0.1.0/shorekeeper-landscape-deepseek-v010.mp4) · [中文](README.md)

![Shorekeeper DeepSeek Pet](docs/social/cover-landscape.jpg)

A Windows desktop companion for the official [DeepSeek Harness client](https://www.deepseek.com/harness/). This edition supports the custom GIFs, voice/subtitle pairs, resizing, and portable settings of [Shorekeeper Codex Pet](https://github.com/Doya16/shorekeeper-codex-pet).

Download and sign in to Harness. Extract the pet bundle and run **守岸人DeepSeek桌宠启动.exe**. Fully quit Harness from its tray menu, open the pet’s appearance/sound/migration settings, choose **连接 DeepSeek → 安装 / 更新 Harness 连接插件**, and reopen Harness.

Task stages animate the pet; concurrent completions queue separately. Each action supports a randomized voice pool with paired captions, playback speed and repeat settings. Thinking speech defaults to once per turn. Idle speech can play on every entry, once per launch, or occasionally.

The balance badge displays money, including bonus balance, rather than a fabricated percentage. Export a complete portable bundle to take GIFs, fonts, voice clips, captions and settings to another computer. Install/sign in to Harness and install the connection plugin there again; credentials and chat history are not included.

Tested on Windows x64 with Harness 0.2.0-rc.2. See [validation notes](docs/VALIDATION.md).

Artwork: [Wuthering Waves emoji collection](https://emoji.wuwa.games/), crowdfunding QQ group **1079834905**. Thank you to everyone who funded the Shorekeeper emotes. See THIRD_PARTY.txt for media and font credits.

![Task stages and independent completion alerts](docs/social/showcase.gif)

The Harness window, projects, dialogue and balance shown in the video are fictional demonstrations. The pet and settings show actual application widgets. Includes 83 GIFs, 40 audio files, 54 voice/caption pairs and two fonts.
