# Shorekeeper DeepSeek Pet

A Windows desktop companion for the official [DeepSeek Harness client](https://www.deepseek.com/harness/). This independent preview reuses the custom GIFs, voice/subtitle pairs, resizing, and portable settings of [Shorekeeper Codex Pet](https://github.com/Doya16/shorekeeper-codex-pet).

Download and sign in to Harness. Extract the pet bundle and run **守岸人DeepSeek桌宠启动.exe**. Fully quit Harness from its tray menu, open the pet’s appearance/sound/migration settings, choose **连接 DeepSeek → 安装 / 更新 Harness 连接插件**, and reopen Harness.

Task stages animate the pet; concurrent completions queue separately. Each action supports a randomized voice pool with paired captions, playback speed and repeat settings. Thinking speech defaults to once per turn. Idle speech can play on every entry, once per launch, or occasionally.

The balance badge displays money, including bonus balance, rather than a fabricated percentage. Export a complete portable bundle to take GIFs, fonts, voice clips, captions and settings to another computer. Install/sign in to Harness and install the connection plugin there again; credentials and chat history are not included.

Target: Windows x64, Harness 0.2.0-rc.2. The DeepSeek edition has not yet been published as a GitHub release.
