守岸人 DeepSeek 桌宠 · 保存与迁移

设置自动保存。右键 → 设置 → 保存与迁移，可立即保存、导出配置素材包或 Windows 便携完整包。
完整包携带运行程序、GIF、音频、每条字幕、字体、全部桌宠设置和 Harness 连接插件安装工具。

换电脑：
1. 解压到可写目录。
2. 安装官方 DeepSeek Harness 并登录，然后从托盘完全退出。
3. 启动“守岸人DeepSeek桌宠启动.exe”。
4. 连接 DeepSeek → 安装 / 更新 Harness 连接插件，再打开 Harness。
5. 新任务启动后自动跟随；可以在连接设置中选择会话。

连接设置里的自动启动选项会保存；新电脑第一次手动启动桌宠后恢复。
连接路径、窗口位置和当前会话在完整包中重置，自动适配新电脑。
桌宠包不会携带 DeepSeek 或 Codex 的账户、密钥、聊天、余额缓存。
可导入 Codex 版素材配置；原 Codex 连接路径不会用于 DeepSeek。

移除连接插件：退出 Harness 后，用其 resources/runtime/cli/bin/dsh.cmd 执行
plugin --profile desktop remove dsh-shorekeeper-pet
然后重新打开 Harness。桌宠设置和素材不会被删除。

首次正常启动 Windows 版会创建桌面快捷方式。误删后：设置 → 保存与迁移 → 创建桌面快捷方式。图标样式在设置 → 桌面与声音选择，会随配置一起迁移。

设置 → 版本与更新可选自动／GitHub／镜像加速。连接页面可设置随客户端完全退出而关闭。两项选择随配置迁移，仍需在新电脑手动启动桌宠一次。
