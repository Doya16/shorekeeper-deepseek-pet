# 一键更新

右键桌宠 → **设置 → 版本与更新 → 一键更新**。默认每 6 小时检查一次，可设置为 1–168 小时，或关闭定时检查。启动检查可以单独开关；下载来源可选自动、GitHub 或镜像。

发现新版时，桌宠旁会出现无声更新气泡。点击 **更新并重启守岸人**，即可完成下载、校验、更新和重启。语音台词出现时会暂时覆盖更新提醒，台词结束后提醒恢复。点击 **今日不再提醒** 后，当天重启也不会再显示。

更新只下载程序文件，不重复下载 GIF、音频、字幕、字体和个人配置。更新前保存当前设置；新版成功启动后才确认完成。更新中请保留安装目录，不要手动移动其中的文件。

更新清单由发布者离线密钥签名（Ed25519），公钥内置在程序中。无论清单和程序包经 GitHub 还是第三方镜像传输，签名不对就不会安装；程序包和每个程序文件的哈希都来自已签名的清单。镜像仍可能延迟、不可用，或显示实际无法安装的版本提醒；要避开镜像，可把更新来源固定为 GitHub。

下载中断时，现有程序不变。下次启动清理未完成的下载，再次点击更新会重新下载。安装中断或新版启动验证失败时，会恢复更新前的版本和设置。更新前的程序与设置备份保存在安装目录中，不会自动删除你的素材。

在 **设置 → 保存与迁移** 仍可导出配置素材包或便携完整包。便携包仅携带当前运行版本，不携带下载缓存、旧程序备份或账户资料。

首次从没有一键更新功能的旧版升级，仍需先安装这次提供的更新包；安装本版以后可在桌宠内完成后续更新。
