# 守岸人 DeepSeek 桌宠使用说明

完整介绍与安装步骤见 [项目说明](../README.md)。本版连接官方 DeepSeek Harness Windows 客户端。

## 首次连接

登录 Harness，从系统托盘完全退出。启动桌宠，右键 → 外观、声音与迁移 → 连接 DeepSeek → 安装 / 更新 Harness 连接插件，再打开 Harness。

## 常用设置

| 想做什么 | 在哪里操作 |
| --- | --- |
| 跟随任务状态 | 右键 → 自动跟随当前任务 |
| 给动作选择 GIF | 交互工作室 → 左侧动作 → GIF 素材 |
| 添加自己的素材 | GIF 素材 → 打开素材目录 / 导入图片，之后刷新 |
| 设置循环、速度、下一状态 | 交互工作室 → 播放与切换 |
| 多条语音随机播放、每条单独配字幕 | 交互工作室 → 语音与配对气泡 |
| 只显示音频对应的字幕 | 气泡与字体 → 气泡内容 → 自定义音频+字幕 |
| 调整待机语音频率 | 待机动作 → 自动播报频率 |
| 只在每轮任务开始说一次 | 思考动作 → 同一轮任务只播一次 |
| 缩放桌宠 | 右键 → 调整大小；或 Ctrl + 滚轮 |
| 改气泡和余额条大小 | 拖动各自左右边缘；或大小设置中的预览控制 |
| 查看金额 | 桌宠底部余额条；悬停看明细；右键刷新余额 |
| 随 Harness 自动启动 | 外观、声音与迁移 → 连接 DeepSeek |
| 保存、导入或导出便携包 | 外观、声音与迁移 → 保存与迁移 |

支持 GIF、动画 WebP、PNG、JPG/JPEG；语音支持 WAV、MP3、OGG、FLAC、M4A、AAC；字体支持 TTF、OTF、TTC。

换电脑时导出 Windows 便携完整包。新电脑安装、登录官方 Harness 后，再安装一次连接插件。可以导入 Codex 版配置素材继续使用；账户和聊天记录不随桌宠包携带。

## 检查更新与升级

每次启动桌宠后自动检查 GitHub 正式版，有新版时提示。也可右键 → **检查更新…**；在 **外观、声音与迁移 → 版本与更新** 中关闭启动检查、手动检查或恢复已忽略版本的提醒。检查失败不会打断使用。

新版提示提供打开更新页、备份配置与素材、稍后提醒和忽略该版本。更新需要手动下载安装：

1. 在 **保存与迁移** 中导出配置与素材 ZIP，保留一份备份。
2. 若发布页提供适用于当前版本的程序补丁，退出桌宠后将补丁解压到原目录覆盖，再重新启动。个人配置、GIF、音频、字幕和字体保留。
3. 若使用完整包，解压到新目录，再导入自己的配置与素材 ZIP。程序补丁直接解压覆盖，不在配置导入窗口中打开。

当前版本和下载链接见 [项目首页](../README.md)。Windows 音量合成器中可通过 **守岸人 · DeepSeek** 单独调整桌宠音量；托盘图标单击可唤醒或隐藏桌宠。
