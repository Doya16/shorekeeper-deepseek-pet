# v0.6.4 陪伴功能与按 token 计费

- 本轮花费改为按 token 用量和 DeepSeek 官方价格估算，和完成动画同时出现，不再等余额刷新。
- 飘字同时显示本轮用时；完成时撒花。设置里可以勾选计费、计时并调整上下顺序，撒花可单独关闭。
- 飘字可选字体、字号、描边和起点（默认桌宠内顶部居中），也可以拖动微调位置。
- 贴边藏起：把桌宠拖到屏幕左右边缘松手，会换成探头动作藏在边上，露出一截墙；左侧自动镜像。鼠标移上去或有提醒时探出来。
- 全屏时隐藏：右键菜单“点击开启全屏时隐藏”，默认关闭。
- 每日小结：每天第一次打开时用气泡说说上一次的完成轮数、出错次数、花费和最长一轮；右键“今日小结”随时查看。
- 喝水和久坐提醒：默认连续使用 60 分钟提醒一次，可选 30 分钟后再提醒、知道了或关闭提醒。
- 设置页改为分组卡片，控件不再拉满整行；滚轮要先点选控件才会改数值。交互工作室可以向下滚动，素材列表更大。

需要连接插件 0.1.3 才能按 token 计算：更新程序后在“设置 → 连接 DeepSeek”重新安装一次连接插件。插件仍是旧版时自动改用前后余额差，飘字最多等 5 秒。

## 计算方式

插件在一轮任务中累计每次模型回复的输入（缓存命中、未命中）和输出 token，连同模型名和所在小时随完成事件发给桌宠，子代理的用量计入启动它的那一轮，联网搜索和网页抓取按成功次数计。桌宠按 DeepSeek 官方定价页（2026-11-11）的人民币价格计算，北京时间工作日 9–12 点、14–18 点为高峰价，其余时间半价；法定节假日按工作日计，可能偏高。Harness 生成会话标题和搜索内部调用模型时不留用量，这部分不计入。

## 验证

- 266 项 Python 测试、11 项连接插件 Node 测试通过，无窗口模式。覆盖价格计算、飘字与完成同步、贴边与镜像、全屏避让、撒花、每日小结、休息提醒、设置页布局和滚轮。
- 打包 EXE（源码提交 bb34407）：从公开 v0.6.3 经一键更新升级到 v0.6.4，GitHub 由本机代理模拟，校验真实签名；254 个素材文件哈希和个人设置不变。
- 升级后的打包 EXE 接收一轮带 token 用量的模拟任务：飘字和撒花在任务结束后 0.7 秒内同时出现（桌宠每 0.5 秒读取一次状态），撒花和飘字随后自动关闭。
- 新插件在本机真实 DeepSeek Harness 中跑过两轮真实任务，完成事件里带有 token 用量（例：缓存命中 9728、未命中 1367、输出 2），用 30 天本机会话记录回放核对字段和子代理归属。
- 全屏检测在真实 Windows 上对一个全屏游戏窗口判断正确。

## 未覆盖

贴边藏起和拖动微调没有在真实桌面上用鼠标拖过，多显示器、高 DPI 缩放下的位置只在模拟屏幕上验证。估算金额没有和 DeepSeek 后台账单逐笔对账。中国大陆网络和各类安全软件未验证。
