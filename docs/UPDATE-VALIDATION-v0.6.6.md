# v0.6.6 飘字样式

- 飘字的计费和计时两行可以分别设置加粗、斜体，并在调色盘中自定义颜色，“默认颜色”一键恢复；“完成播报”预览同步显示。
- 加粗不再依赖系统的假粗体：字体有粗体字形时使用粗体，没有时由程序加粗，边缘保持清晰。

## 验证

- 288 项 Python 测试、11 项连接插件 Node 测试通过，无窗口模式。覆盖样式选项的默认值和校验、加粗斜体和颜色在飘字上的实际像素、调色盘选择、取消和恢复默认、预览联动。
- 打包 EXE（源码提交 c026e27）：从公开 v0.6.5 经一键更新升级到 v0.6.6，GitHub 由本机代理模拟，校验真实签名；254 个素材文件哈希和个人设置不变。
- 升级后的打包 EXE 接收一轮模拟任务：飘字和撒花在任务结束后 1.1 秒内同时出现，随后自动关闭。
- 加粗、斜体和自定义颜色的飘字样图在无窗口模式下渲染检查；默认窗口尺寸下所有设置页都没有左右滚动。

## 未覆盖
