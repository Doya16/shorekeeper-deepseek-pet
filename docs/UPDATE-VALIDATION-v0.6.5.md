# v0.6.5 贴边改进与设置预览

- 贴边改进：靠边待机和藏起分开。有任务进行、有提醒或气泡、鼠标移上去、离开电脑 5 分钟以上时完整出来；安静到设定时间（默认 60 秒，设置里可调）后才藏起一半。工作时的动画不再被截掉，平时的安静待机也保留。
- 修复两块显示器缩放比例不同时，在交界处贴边藏起，另一半显示到另一块屏幕上的问题：旁边还有屏幕的那条边不再贴边。
- 设置页“字体与大小”“桌面与声音”的每个板块旁新增循环预览，按当前设置演示效果，不影响桌宠；锁定预览带模拟窗口，能看出透明后的效果。
- 设置窗口默认尺寸略调，避免出现左右滚动；飘字起点改为更短的名称。

## 验证

- 278 项 Python 测试、11 项连接插件 Node 测试通过，无窗口模式。覆盖贴边的两种状态与切换、相邻显示器判断（模拟不同缩放比例的屏幕坐标）、各板块预览在整段循环中的画面、设置页布局和滚轮。
- 打包 EXE（源码提交 fb55411）：从公开 v0.6.4 经一键更新升级到 v0.6.5，GitHub 由本机代理模拟，校验真实签名；254 个素材文件哈希和个人设置不变。
- 升级后的打包 EXE 接收一轮模拟任务：飘字和撒花在任务结束后 1.2 秒内同时出现，随后自动关闭。
- 各板块预览在无窗口模式下逐帧渲染检查，默认窗口尺寸下所有设置页都没有左右滚动。
