# v0.6.7 稍后再提醒可自定义

- 休息提醒的“稍后再提醒”可以自己填等多久：在 设置 → 桌面与声音 → 休息提醒 → 稍后再提醒 里填 1～240 分钟（默认 30）。提醒卡片上的按钮显示成“N 分钟后再提醒”，设置页预览同步；改这个数字时，正在倒计时的那次提醒不受影响，“知道了”仍按提醒间隔重新计时。
- 台词结尾不再被吞掉：以前每句播完时，最后一小段还在声卡缓冲里就停止了输出；现在台词后留 0.4 秒静音再停止。
- 设置窗口按屏幕大小打开：字体列表单独占一行，第一页不再超出窗口，每个板块旁的预览卡片都能完整显示。
