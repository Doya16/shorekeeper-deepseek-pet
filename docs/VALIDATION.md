# v0.1.0 验证记录

验证环境：Windows x64、官方 DeepSeek Harness 0.2.0-rc.2、桌宠连接插件 0.1.2。

| 检查 | 结果 |
| --- | --- |
| 真实任务读取、写入、回读文件 | 思考、查阅、编写和完成状态正常切换 |
| 等待选择与恢复 | 主题选择期间显示等待，提交答案后继续执行并完成 |
| 两个会话同时活动 | 一个等待时，另一个完成的通知和语音独立触发；前一个随后完成也单独提醒 |
| 手动中止 | 客户端停止生成后产生暂停事件 |
| 客户端重启、插件更新 | 重连成功，安装文件与发布插件逐项校验一致 |
| 账户余额 | 已登录账户可读取金额；科学计数法、空余额和退出账户的延迟响应均有回归检查 |
| 语音与字幕 | 多条完成语音按顺序播完整；同一轮思考去重；待机启动一次模式不会在完成后重复播放 |
| 设置与交互 | 68 项 Python 检查通过，涵盖 GIF、配对字幕、播放策略、字体、大小、导入导出和配置保存 |
| 原生窗口操作 | 气泡与余额条边缘拖动即时保存；缩放预览不触发交互语音 |
| 随客户端启动 | Windows 启动项与后台等待程序实际验证；取消联动后退出，测试结束恢复原设置 |
| 插件事件 | 8 项 Node 检查通过，涵盖真实事件格式、并发、审批等待、结束去重和账户状态 |

发布完整包还会在中文及空格路径下启动，使用仅含 Windows 系统目录的 PATH 检查程序、字体、GIF 和音频组件；导入后再次导出，并比较所有素材文件的 SHA-256。换电脑验证使用本机隔离目录和隔离运行环境，未在第二台实体电脑上测试。
