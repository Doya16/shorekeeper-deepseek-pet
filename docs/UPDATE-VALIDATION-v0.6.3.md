# v0.6.3 本轮花费提示

任务结束后显示本轮花费：默认在余额框上方飘字，可在“设置 → 桌面与声音 → 本轮花费提示”改成气泡、飘字和气泡，或关闭。

只改桌宠程序，更新校验和恢复代码未改动。

## 计算方式

任务开始时记录余额，结束后刷新余额，取第一次低于开始值的读数计算差值。最多等待 30 秒，余额没有变化就不显示。多个任务同时进行时，气泡注明“这是合计”，飘字不单独注明。为此发起的余额刷新不显示“刷新中”。

## 验证

- 169 项 Python 测试通过，无窗口模式。
- 打包 EXE（源码提交 5df84e6）：从公开 v0.6.2 经一键更新升级到 v0.6.3，GitHub 由本机代理模拟，校验真实签名；素材哈希和个人设置不变。
- 升级后的打包 EXE 接收模拟任务和余额：任务结束约 4 秒后飘字窗口出现，并自动关闭。
- 设置页的四个选项在无窗口模式下逐一保存通过，默认值为飘字。

## 未覆盖

金额和任务都是模拟数据，没有用真实计费任务验证扣费到账延迟，因此实际显示的时间和金额可能与模拟不同。中国大陆网络和各类安全软件也未验证。

以上为项目自行验证的结果，不代表独立安全审计。
